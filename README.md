# LED clock custom control

WPF custom control built **entirely in C#** with WPFX.

## `LedClockControl`

A 7-segment LED clock custom control.

### Properties

- `Timestamp` (`DateTime`)
- `IsSecondsColonFlashEnabled` (`bool`)
- `IsMinutesColonFlashEnabled` (`bool`)
- `IsGlowEffectEnabled` (`bool`)

### Events

- `TimestampChanged`
